# Self-hosted Google Fonts

Added by Stateloop packaging so players' browsers never contact Google. The files are the exact
stylesheets and WOFF2 files Google Fonts serves for the game's own font request; each family keeps
its licence from google/fonts at e7db6ca603fd4862010383ff17ffd6cc4ffac1c0.

- Chakra Petch: OFL-1.1 (google/fonts `ofl/chakrapetch/OFL.txt`)
- Orbitron: OFL-1.1 (google/fonts `ofl/orbitron/OFL.txt`)

Source stylesheets:

- `https://fonts.googleapis.com/css2?family=Orbitron:wght@500;600;700;800;900&family=Chakra+Petch:wght@300;400;500;600;700&display=swap` (sha256 07d9aec053e7884f63527a32322a3ebc5a1354bcd578549e1d59753c1c3b101b)
